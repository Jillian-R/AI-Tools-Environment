# AI Tools and Environment Setup

This repository contains files created for the AI Tools and Environment Setup mini project.

## Environment

- Python virtual environment
- Visual Studio Code
- Jupyter Notebook
- Git and GitHub

## Project Files

- `hello.py` - verifies Python execution
- `setup_demo.ipynb` - verifies Jupyter notebook execution
- `requirements.txt` - lists required Python dependencies
- `.gitignore` - prevents local environments and credentials from being committed
